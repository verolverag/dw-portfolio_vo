# Portafolio Verónica Olvera

Sitio web de portafolio personal desarrollado como proyecto del curso de Desarrollo Web.

El proyecto reúne trabajos de Diseño Gráfico, UX/UI y proyectos de autor, con una estructura responsive para distintos dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass / SCSS
- Bootstrap 5
- Git y GitHub

## Sass

Los estilos del proyecto están organizados mediante partials de Sass en las carpetas:

- utilities
- base
- layout
- components

El archivo SCSS principal compila los estilos utilizados por el sitio.
