
# Portafolio Verónica Olvera

Portafolio personal desarrollado como proyecto final del curso de Desarrollo Web de CoderHouse.

Este sitio reúne algunos de mis trabajos de diseño gráfico, branding, UX/UI e ilustración, además de información sobre mi experiencia y trayectoria profesional.

El objetivo fue crear una página web responsive, funcional y coherente con mi identidad visual, aplicando los conocimientos adquiridos durante el curso.

- [Ver portafolio en GitHub Pages](https://verolverag.github.io/dw-portfolio_vo/)

## Secciones del sitio

El portafolio está compuesto por cinco páginas:

1. **Inicio:** presentación personal, áreas creativas y proyectos destacados.
2. **Sobre mí:** trayectoria profesional, experiencia, habilidades e intereses creativos.
3. **Mis Proyectos:** selección de trabajos de branding, diseño gráfico y UX/UI.
4. **Negro Ámbar Studio:** ilustraciones realizadas con tinta china y puntillismo.
5. **Contacto:** enlaces a redes profesionales e información para colaborar en nuevos proyectos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass / SCSS
- Bootstrap 5
- AOS (Animate On Scroll)
- Git y GitHub
- Netlify y GitHub Pages

## Características del proyecto

- Diseño responsive para mobile, tablet y desktop.
- Estructura HTML semántica.
- Navegación responsive con Bootstrap.
- Uso de Flexbox y CSS Grid.
- Estilos organizados mediante Sass.
- Variables, mixins, nesting, extend y partials.
- Animaciones y transiciones CSS, además de AOS.
- SEO básico mediante títulos, metadescripciones y textos alternativos.

## Organización de Sass

Los archivos SCSS están organizados en las siguientes carpetas:

- `utilities/`: variables, mixins y extend.
- `base/`: reseteo, estilos generales y tipografía.
- `layout/`: estilos de las diferentes páginas y elementos estructurales.
- `components/`: botones y tarjetas reutilizables.

El archivo `scss/main.scss` reúne los partials mediante `@use`.

El CSS compilado se encuentra en `styles/styles.css`.

Para observar los cambios de Sass durante el desarrollo se utiliza:

```bash
npm run watch
```
